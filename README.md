# Paradise Nursery

## Project Details

**Paradise Nursery** is a plant shop application designed to help users browse and purchase beautiful plants for their homes and gardens.

### Features

- Plant product listing with images, names, categories, and prices
- Add plants to the shopping cart
- Increase or decrease product quantities
- Remove products from the cart
- Display total cart items and total price
- Responsive and user-friendly plant shop interface

### Technologies

- React.js
- Redux Toolkit
- JavaScript
- CSS

## Project Name

**Paradise Nursery Plant Shop**
